ADESIVA — PWA / STICKER STUDIO

Conteúdo:
- index.html: biblioteca de adesivos, editor, categorias, pesquisa e cópia/PNG.
- manifest.webmanifest: dados para instalação como PWA.
- sw.js: cache básico para abrir novamente quando offline.
- icon-192.png e icon-512.png: ícones.

Biblioteca:
- Adesivos com versículos, saudações, dias da semana, procedimentos e Fitness.
- Nova aba Elementos com ilustrações vetoriais transparentes: flores, corações, borboleta, brilhos, laço, folhas, seringa estética, skincare, máscara facial, halter e hidratação.
- Os elementos podem ser filtrados por subcategoria, copiados como PNG ou enviados ao editor para combinar com textos.
- Adesivos criados e imagens adicionadas pelo editor são guardados localmente no navegador deste aparelho (IndexedDB, com alternativa localStorage). Não há sincronização entre aparelhos ou conta de usuário.

Publicação:
1. Em Settings > Pages, escolha Deploy from a branch, branch main e folder /(root).
2. Aguarde o endereço HTTPS gerado pelo GitHub Pages.
3. Abra o endereço no Safari do iPhone > Compartilhar > Adicionar à Tela de Início.

A cópia de imagens depende do suporte do navegador e do iOS/Safari. O botão PNG é uma alternativa quando a colagem direta não estiver disponível.
