ADESIVA — PROTÓTIPO PWA

Conteúdo:
- index.html: biblioteca, filtros, criação simples e botões Copiar/PNG.
- manifest.webmanifest: dados para instalação como PWA.
- sw.js: cache básico para abrir novamente quando offline.
- icon-192.png e icon-512.png: ícones.

IMPORTANTE:
Este pacote ainda não está publicado na internet. Para o botão Copiar funcionar de forma confiável, publique em um endereço HTTPS.
No iPhone, a cópia de imagem depende da versão do iOS/Safari e das permissões do navegador. O Instagram pode não aceitar colagem de imagem em todos os fluxos. O botão PNG é uma alternativa.

Publicação simples:
1. Extraia o ZIP.
2. Crie um repositório no GitHub e envie os arquivos para a raiz.
3. Em Settings > Pages, escolha Deploy from a branch, branch main e folder /(root).
4. Aguarde o endereço HTTPS gerado pelo GitHub Pages.
5. Abra esse endereço no Safari do iPhone > Compartilhar > Adicionar à Tela de Início.

Os adesivos criados nesta versão ficam apenas na memória da página durante a sessão. Ainda não há conta, sincronização, armazenamento permanente ou IA.
